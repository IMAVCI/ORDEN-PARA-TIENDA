2. Llévalo a las webs que quieras

Una página no puede cambiar lo que el navegador entrega a otras páginas. Por eso el ancla viaja contigo de una de estas tres formas. El código de abajo ya lleva tu punto.

Marcador Cualquier navegador, móvil u ordenador. Lo pulsas en cada página.

En ordenador: arrastra este botón a tu barra de marcadores.

Anclar ubicación

En móvil: guarda cualquier página como marcador, edítalo y pega este código en el campo de la dirección.

Abre la web y pulsa el marcador antes de que te pida la ubicación. Si recargas la página, púlsalo otra vez. En Chrome para Android se lanza escribiendo su nombre en la barra de direcciones.

Script permanente Se activa solo en cada visita. Necesita una extensión de scripts.
  1. Instala Tampermonkey o Violentmonkey. En Android funcionan con Firefox; en iPhone, con la app Userscripts para Safari.
  2. Crea un script nuevo, borra lo que traiga y pega este.

Sin instalar nada Chrome o Edge en ordenador, mientras tengas abiertas las herramientas.
  1. En la web que quieras, pulsa F12.
  2. Abre el menú de tres puntos, Más herramientas, Sensores.
  3. En Ubicación elige Otra… y escribe tu punto: primero ancla un punto

Lo que el ancla no cambia

  • Las apps instaladas en el móvil: leen el GPS del sistema, no el del navegador. En Android eso se hace con una app de «ubicación simulada» desde las opciones de desarrollador.
  • La ubicación aproximada que una web deduce de tu dirección IP.
  • Una web que ya estaba siguiendo tu posición antes de activar el ancla. Actívala primero.
